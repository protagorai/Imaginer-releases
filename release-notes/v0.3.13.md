# Imaginer 0.3.13 for Apple silicon

Published **5 October 2026** · Version **0.3.13** · Development build for **macOS / Apple silicon (arm64)**.

This release expands layer styling, editable objects and retouch tools, improves paint and workspace controls, and protects changed documents when closing them.

## Added

- Editable clipping masks that keep upper layers inside a named base layer, with layer controls and working-version recovery. Earlier upper-alpha masks migrate as **Alpha mask** while preserving their appearance.
- 27 layer blend modes, separate opacity and fill, and editable overlays, strokes, shadows, glows, bevel and satin. The Blending dialog offers live preview, Apply and Cancel.
- Editable Rectangle, Ellipse, Triangle, Polygon, Star and Line layers; Scale, Distort, Skew, Mesh Warp, flips and rotations for supported raster, text and vector targets.
- Crop with draggable bounds and numeric fields, Clone Stamp, Eyedropper sampling options, and Smudge and Sharpen alongside Blur.
- Pencil with crisp pixels and Auto Erase, plus independent paint-tool settings and fine/exact size controls.
- Configurable keyboard shortcuts and versioned JSON import/export for moving shortcut maps between installations.
- Save, Don't Save and Cancel choices when closing changed documents or the app; a scrollable document list with individual close controls and Close all.

## Updated

- Numeric tool and effect settings pair sliders with exact fields. Paint controls remember separate values per tool and support one-pixel size shortcuts.
- Stroke previews update affected canvas rectangles and retain coalesced pointer samples for fast gestures.
- Guides extend across the viewport, support fine positioning near snap targets, and can be removed with a quick outward drag.
- Unsupported layered PSDs can offer an explicit flattened-preview choice. Preview sources may be up to 300 MiB; supported 16-bit RGB previews are reduced to 8-bit with a notice about color and editability limits.
- Working snapshot version 5 preserves clipping relationships, editable objects and crop coordinates; earlier supported snapshots remain readable.

## Fixed

- Selection dismissal recognizes clicks outside the selection or image while preserving clicks inside it.
- Loading a layer's opaque pixels from its thumbnail keeps the active layer unchanged and uses the documented opacity threshold.
- Guide removal recognizes outward releases near image and window edges.
- Legacy PSD full-layer locks survive import and PSD save. PSD resolution below 1 PPI falls back to 96 PPI with an explicit notice.

## Compatibility and known limits

- The installer is for Apple silicon and requires macOS 13 or later. Other desktop installers are planned separately. The minimum requirement is not a claim that every compatible OS version was tested.
- Editing uses 8-bit RGBA. GIF and animated WebP open as a single frame. Embedded ICC profiles are not applied to PSD flattened previews, so their colors may differ.
- PNG is flattened. PSD and OpenRaster save supported raster layers and report unsupported editable features; Imaginer's temporary working versions retain supported text, vector and effect data.
- Editable imports are limited to 100 MiB per file and 64 million decoded pixels. The separate PSD flattened-preview path accepts sources up to 300 MiB. Normal document close or quit discards that document's working versions; save a lasting output before closing.

Imaginer is **closed-source**. The application project source is private and is not published or offered for download. This release distributes the built installer.
